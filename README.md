# 🚀 Dijkstra Based Mapper

A path-finding and mapping system that computes optimal routes using **Dijkstra's Shortest Path Algorithm**. The project uses a **FastAPI backend** for processing graph data and a **React frontend** for user interaction.

---

## 📌 Overview

The system models a network of nodes and weighted edges representing distances or costs between locations. Using Dijkstra's algorithm, it determines the shortest path between any two nodes.

### 🔧 Backend Responsibilities
- Load graph data from a CSV dataset
- Compute shortest paths
- Expose API endpoints for route queries

### 💻 Frontend Responsibilities
- Interact with backend APIs
- Display computed shortest paths

## 🧠 Algorithm

**Steps:**
1. Initialize start node distance = 0  
2. Set all others to infinity  
3. Pick node with smallest distance  
4. Update neighbors  
5. Repeat until destination is reached
